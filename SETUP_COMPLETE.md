# Setup notes

The project is configured as a Next.js application using TypeScript and Tailwind CSS.

## Included application areas

- School discovery and school profiles
- Account registration and sign-in
- Application creation, submission, and tracking
- Parent, school-admin, and platform-admin dashboards
- Paystack payment endpoints

## Local configuration

Use `.env.example` as the starting point for `.env.local`. Do not commit `.env.local` or the `.data` directory; both may contain local configuration or user records.

## Useful commands

```bash
npm run dev
npm run build
npm start
```

See `README.md` for the project overview and `QUICK_START.md` for local startup steps.
